# INS Manager

인스송일헌 내부 보험 조회 시스템입니다.

## 주요 기능

- 위탁사명 및 관리번호로 단지 조회
- 보험기간 및 월보험료 확인
- 직원 구성 및 피보험자 구성원 확인
- 보험증권, 납부안내문, 보증서 PDF 열기
- PC 및 모바일 반응형 화면
